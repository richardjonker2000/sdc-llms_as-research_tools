# Additional materials

Not taught in the sessions: for after the workshop, or for anyone who finishes early. Each notebook works like the lesson 1 notebooks (prompts and code visible, saved answers, a cost line under every cell).

| Notebook | What it shows | Builds on |
| --- | --- | --- |
| `A1_your_data` | **Your own CSV and your own codebook**: test on 3 rows, then run everything, with a cost estimate for your dataset | lesson 1 · 01, 02 |
| `A2_long_documents` | Long documents: extract per document, then aggregate, checked against the registry | 01 |
| `A3_rewriting` | Cleaning firm names, translating while keeping the voice, anonymising interview snippets | 01 |
| `A4_literature_lenses` | More views on the field map: hidden connections, schools of thought, what is emerging, a one-page memo | 04 |
| `A5_patent_task_match` | Which work tasks could an AI patent perform? From patents to occupations | 01, 02 |
| `A6_decision_models` | A small local model (needs Ollama) that answers with probabilities: automate the confident cases, hand-code the rest | 02 |

`prompts_chatbot_track.md` is lesson 1 for any chatbot, without code.
