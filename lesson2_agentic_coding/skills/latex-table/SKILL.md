# Results → LaTeX table

The table is generated by a script from the results file, never typed by hand, so it can be regenerated when the results change.

## Ask first (method: the researcher decides)

1. **Which results file** and which rows and columns; counts, percentages or both (row or column percentages?).
2. **Rounding** (decimals) and how to mark significance, if at all.
3. Caption and label (`tab:<name>`), or draft them for approval.

## Steps (one script: `analysis/tab_<name>.py` → `outputs/tab_<name>.tex`)

```python
import pandas as pd
res = pd.read_csv("outputs/<results>.csv")
body = res.to_latex(index=False, escape=True, float_format="%.2f",
                    column_format="l" + "r" * (res.shape[1] - 1))
# wrap in table + caption + label; the paper needs \usepackage{booktabs}
```

- Numbers right-aligned, text left. One decimal place convention per column.
- Percent signs go **inside** the brackets: `9 (81.8\%)`, never `9 (81.8)\%`.
- Escape `& % $ # _ { }` in text cells.

## Required checks (always in the report)

| Check | How |
| --- | --- |
| Numbers match the source | the script re-reads the `.tex` it wrote and compares every number with the results file; print the count of mismatches (must be 0) |
| It compiles | `pdflatex` on a minimal document that `\input`s the table, if LaTeX is installed; otherwise say "not compiled" |
| Totals add up | row/column totals and percentages sum as expected (100% ± rounding) |

Say "checked" only for what was checked. Formatting is not checked by comparing numbers.

## Never

- type or edit numbers by hand in the `.tex` file;
- round in a way that changes a conclusion (e.g. 0.049 → 0.05 next to a significance star) without flagging it.
